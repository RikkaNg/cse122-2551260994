# TinHocPortal – Bài tập lớn CSE122 (Phát triển ứng dụng Web cơ bản)

Hệ thống hỗ trợ giảng dạy và học tập môn **Tin học đại cương** (Web Frontend nguyên mẫu, nhiều vai trò, CRUD qua Mock API / LocalStorage, responsive, tương tác JavaScript trực quan).

## Thông tin học phần
- **Học phần:** Phát triển ứng dụng Web cơ bản – `CSE122`
- **Nhóm thực hiện:** 3 sinh viên (`SV1`, `SV2`, `SV3`)
- **Loại sản phẩm:** Web Frontend nguyên mẫu (HTML / CSS / JavaScript + Mock API)
- **CSDL giả lập:** `db.json` (JSON Server / MockAPI / LocalStorage)
- **Minh chứng bắt buộc:** Mỗi màn hình đã duyệt = 1 video OBS giảng giải + khả năng làm lại được.
